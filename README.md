# magneto-navigator

travelers guide for mastering magnetism: a one-page reference for the **strymon magneto** four head dtape echo & looper. echo, loop and sample modes, tap and speed, head spacing and clock outs, transport, pitch quantize scales, self-oscillation, cv inputs, dip switches and the button combos, with diagrams.

source: the [strymon magneto user manual, rev b](https://www.strymon.net/support/magneto/).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with strymon.
